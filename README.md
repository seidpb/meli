# Meli — ručno heklane amigurumi lutke

Statički sajt (bez build koraka).

## Struktura
- `index.html` — sajt (Početna, O meni, Galerija, Kontakt)
- `support.js` — potrebna skripta, mora biti pored `index.html`
- `slike/`, `assets/` — fotografije

## Objavljivanje (GitHub Pages)
1. Postavi sve fajlove u koren repozitorijuma.
2. Settings → Pages → Branch: `main`, folder `/ (root)` → Save.

## Lokalno
Pokreni lokalni server u ovom folderu (npr. `npx serve .`) i otvori adresu u pregledaču.
